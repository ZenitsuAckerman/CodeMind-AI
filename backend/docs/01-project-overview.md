# CodeMind AI: Project Overview

## What is CodeMind AI?
CodeMind AI is an AI-powered Engineering Knowledge Workspace. It serves as a central hub for engineering teams to upload, query, and interact with their source code, documentation, and architecture diagrams using Retrieval-Augmented Generation (RAG).

## Key Features (Future Sprints)
- User Authentication & Management
- Project Workspaces
- Artifact Uploads (Source Code, Markdown, PDFs)
- AI Chat Assistant via RAG

## Tech Stack
- **Backend Framework**: FastAPI (Python 3.13)
- **Database**: PostgreSQL (via asyncpg and SQLAlchemy 2.x)
- **Migrations**: Alembic
- **Configuration**: Pydantic V2
